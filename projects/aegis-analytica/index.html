01 / OVERVIEW

Aegis Analytica

Customer Feedback File Analyzer

An applied machine learning web application that automates sentiment extraction and classification across unstructured customer feedback datasets, visualizing actionable metrics via an interactive dashboard.

Focus AI / Machine Learning & NLP
Stack Python · FastAPI · Scikit-learn · React · Docker
Source GitHub Repository ↗
02 / THE PROBLEM

Unstructured Ingestion Bottlenecks

Customer review and feedback streams arrive as unstandardized tabular files and raw text. Manually triaging large volumes of feedback introduces operational bottlenecks and inconsistent sentiment labeling.

The objective was to create a lightweight, modular system capable of parsing uploaded feedback datasets, vectorizing lexical features, computing granular sentiment scores, and returning structured visual summaries without external API latency or heavyweight model overhead.

03 / WHAT I BUILT

Modular NLP Service & Interface

A decoupled full-stack architecture consisting of:

  • A non-blocking FastAPI backend providing asynchronous endpoints for file uploads, schema validation, and text normalization.
  • An NLP classification pipeline leveraging Scikit-learn and Pandas for lexical feature extraction, token cleaning, and sentiment categorization.
  • A responsive React frontend with interactive filtering, sentiment category breakdowns, and keyword distribution views.
  • A Docker container configuration ensuring seamless reproduction across runtime environments.
04 / HOW IT WORKS

End-to-End Ingestion Workflow

  1. File Upload: User uploads tabular feedback documents (CSV/Excel) through the React UI.
  2. Validation & Cleaning: FastAPI validates row schemas, cleans text, and strips noise tokens.
  3. Inference & Scoring: Pre-trained Scikit-learn classification pipelines score each text entry.
  4. Aggregation: Pandas aggregates sentiment distributions and polarity distributions.
  5. Visualization: The client renders instant visual summaries and keyword breakdowns.

07 / ENGINEERING DECISIONS

Technical Trade-Offs

  • 01 / Modular Ingestion Layer

    Separated data transformation logic from HTTP transport routes, enabling pipeline iteration without altering API endpoints.

  • 02 / Lexical Vectorization Choice

    Selected Scikit-learn and Pandas vectorization for fast local inference and low CPU/memory footprints over heavy transformer models.

  • 03 / Container Orchestration

    Configured Docker containerization to eliminate local dependency mismatches and guarantee deployment parity.

08 / WHAT I LEARNED

Key Technical Insights

Decoupling the ingestion, normalization, and model inference steps makes text analysis services significantly easier to unit test, profile, and extend when handling messy real-world datasets.
